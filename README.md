# AsistNet - Sistema de Gestión de Asistencia Estudiantil

Sistema web frontend para la gestión de asistencia estudiantil.

## Características
- 11 páginas HTML completas
- CSS modular organizado
- JavaScript por funcionalidad
- Diseño responsive

## Páginas Incluidas
- index.html (Página principal)
- templates/login.html
- templates/registro.html
- templates/dashboard.html
- templates/perfil.html
- templates/consulta_asistencias.html

## Uso
1. Clonar repositorio
2. Abrir index.html en navegador
3. Navegar entre páginas
